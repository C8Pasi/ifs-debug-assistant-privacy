Privacy Policy

Change8 Permission Debugger

Last updated: 1 October 2026

Change8 Permission Debugger is a browser extension that helps users and administrators understand permission and access errors in IFS Cloud. When an error or access-denied message appears, it captures the related API request and shows the projection, action, status, and error details, and can look up and grant the permission-set access needed to resolve it.

Data the extension handles

  • Connection settings you enter — the IFS base URL, realm, and the permission-lookup client credentials you provide in the extension's Settings.
  • Error details from IFS Cloud — for requests that result in an error, the extension records the page URL, page title, time, HTTP status, and the request and response content. This content can include information such as a username referenced in the error.

How the data is used

The data is used solely to detect, display, and help resolve IFS Cloud errors within the extension's side panel — and, when you choose, to look up and grant the permission-set access that resolves them.

Where the data goes

All captured data and settings are stored locally in your browser using Chrome's storage. The extension communicates only with the IFS Cloud server you configure, using the credentials you provide.

The extension does not send your data to the developer or to any third party, and does not sell or transfer your data.

Data retention

Captured error records and settings remain in your browser until you clear them — using the extension's Clear action, or by removing the extension.
